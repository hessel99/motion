# Flat illustration explainer
> Friendly flat illustrations from simple shapes, clear icons and step-by-step reveals that explain one idea per beat.

**Use for**: product explainers, onboarding, how-it-works, education, app store videos.

## Palette
- Background `#EAF4F4` or `#FFF8F0`; ink `#22313F`.
- Illustration set: `#FF7F50` coral, `#2EC4B6` teal, `#FFBF69` amber, `#3D5A80` navy, `#FFFFFF` highlights. No gradients; at most 2 shades per hue.

## Shapes
Objects built from rects/ellipses/paths: phone (rounded rect + screen), coins, documents, people (circle head + pill body), connectors (stroke paths with trim). One radius family (12–24).

## Typography
Inter 700 headlines 64–88 px, Inter 500 labels 28–36 px; short labels next to icons; captions under each step.

## Easing & timing
Family: `Back Out` (small pops), `Cubic Out` / `Quart Out` (moves), `spring Quick`. Pops 0.3–0.5 s; a new step every 1.5–2.5 s; staggers 0.08–0.12 s; connectors draw in 0.4–0.6 s (`Cubic In Out`).

## Signature moves
- Icon pop: scale 0 → 100 `Back Out` 0.4 s, opacity in the first 30 %.
- Connector draw: arrow path `trimEnd` 0 → 100; the next icon pops when the arrow arrives.
- Object transform: a document slides into a phone (position + scale down); the phone screen changes color (fill).
- Numbered step badges cascade 1–2–3.

## Transitions
Camera pan to the next step (move a parent group, `Cubic In Out` 0.8 s) so steps feel connected; or a match where one object becomes the next scene.

## Do / Don't
- Do: one idea per beat, consistent icon style, short labels, connectors that guide the eye.
- Don't: detailed realism, mixed stroke widths, paragraphs of text.

## Mini scene plan (12 s, 3 beats)
1. 0–4 s: problem — a pile of documents pops in, a frowning face appears; caption "Paperwork piles up".
2. 4–8 s: solution — documents fly on arcs into a phone; the screen turns teal with a check mark.
3. 8–12 s: outcome — an arrow draws to a smiling face, a coin stack pops; logo + CTA.
